# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/claim` | Claim and protect personal land | `` | `/<command> [new/claim/menu/confirm/cancel/spawn/set/chest/toggle/info/list/lines/add/unclaim/trust/untrust/reload]` |
| `/scanchests` | Count an item in your claim chests and withdraw it | `` | `/<command> <item/hand/confirm [amount]/cancel>` |
| `/road` | Root-Road status and admin (Claims onboarding) | `` | `/<command> [status/reload]` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootclaims.use` | Use personal claims | `true` |
| `rootclaims.admin` | Manage all RootClaims and reload config | `op` |
| `rootclaims.bypass` | Bypass claim protections | `op` |
| `rootroad.use` | Receive Root-Road guidance | `true` |
| `rootroad.bypass` | Skip Root-Road onboarding | `op` |
| `rootroad.reload` | Reload root-road.yml | `op` |
